## 이 세션에서 내린 결정 (확정)

1. **아키텍처 = B안**: AI는 최초 POST 때 **딱 1회** 호출, 5방향 결과를 모두 생성해 캐시. 방향 탭 전환은 **프론트에서 화면만 전환**(BE·AI 왕복 없음). → 상세 01 문서.
2. **5방향 전부 노출**: ①빠른졸업(FAST_GRAD) ②전공심화(MAJOR_DEEP) ③학점안정(GRADE_SAFE) ④시험·개별평가(EXAM_SOLO) ⑤협업·활동(TEAM_ACTIVE).
3. **편향 경고**: 편향이 심한 방향(④⑤)엔 `caution` 문자열을 BE가 규칙으로 채워 내려주고, FE는 값이 있으면 **라벨 아래 빨간 글씨**로 렌더. null이면 미표시.
4. **결합 A(개인화)**: 방향 내부에서 성향(profile.py)으로 정렬 + 이유①(성향맞춤) 개인화.
5. **하위호환**: 응답 최상위 `recommendations`(defaultDirection 5개 미러) 유지 → directions가 컷돼도 FE 재작업 없음.
