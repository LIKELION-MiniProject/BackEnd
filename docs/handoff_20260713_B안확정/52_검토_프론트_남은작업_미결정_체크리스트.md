## 1. 프론트엔드 현황 (React 19 + Vite 8 + Router 7)
> ⚠️ FE 코드는 **인서의 별도 레포**(BE와 다름). 이전 세션 산출물은 outputs → FE 레포로 이동 대상.

| 화면 | 상태 |
|---|---|
| 로그인/회원가입 | ✅ 최소 폼 |
| 온보딩 라우팅 | ✅ (⚠️ 프로필 생성 화면만 미구현) |
| 졸업요건 입력(사진1) | ✅ 실 API 연동 |
| 수강내역 입력(사진2) | ✅ 정합 완료(한글↔enum, year/semester 분해, retake, A0/B0) |
| 성적 대시보드(사진3) | 🟡 `semesterGpa`만 반영 필요 |
| AI 분석(기본+비교 2방향) | ✅ 화면 |

- 계약 소비: `data.directions[]`/`defaultDirectionId`/`caution`/`thin`/`category`/`reasons[0/1/2]`/`source`.
- 토큰: localStorage 저장 + `Authorization: Bearer` 주입, 401→로그인. dev는 `/api→localhost:8080` 프록시.

## 6. 직접 검증하는 방법 (서버 켜고 curl — 이번 세션 검증됨)
```powershell
# 서버: .\gradlew bootRun  (JWT_SECRET/JWT_EXPIRATION 환경변수 필요)
# 로그인
$login = Invoke-RestMethod -Method Post -Uri "http://localhost:8080/api/v1/auth/login" -ContentType "application/json" -Body ([Text.Encoding]::UTF8.GetBytes((@{email="demo1@passport.ac.kr";password="Passport1!"}|ConvertTo-Json)))
$h = @{ Authorization = "Bearer $($login.data.accessToken)" }
$pf = (Invoke-RestMethod -Uri "http://localhost:8080/api/v1/auth/me" -Headers $h).data.profileId
# 성적 입력이 진단에 반영되는지
"before " + (Invoke-RestMethod -Uri "http://localhost:8080/api/v1/profiles/$pf/diagnosis" -Headers $h).data.totalCredit.earned
$c = @{name="데이터베이스";credit=3;category="MAJOR_ELECTIVE";grade="A+";year=2025;semester=1;retake=$false}|ConvertTo-Json
Invoke-RestMethod -Method Post -Uri "http://localhost:8080/api/v1/profiles/$pf/courses" -Headers $h -ContentType "application/json" -Body ([Text.Encoding]::UTF8.GetBytes($c)) | Out-Null
"after  " + (Invoke-RestMethod -Uri "http://localhost:8080/api/v1/profiles/$pf/diagnosis" -Headers $h).data.totalCredit.earned   # 늘어나면 OK
# 추천
(Invoke-RestMethod -Uri "http://localhost:8080/api/v1/profiles/$pf/recommendations" -Headers $h).data | ConvertTo-Json -Depth 6
```
- ⚠️ PowerShell 팁: 한글 바디는 `[Text.Encoding]::UTF8.GetBytes(...)`로. 예약변수(`$pid`,`$host`) 금지. 새 터미널은 로그인부터 다시. `gradlew test` 대신 bootRun+curl. bootRun의 80% 표시는 정상(서버 실행 중).
