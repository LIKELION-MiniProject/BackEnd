## 8. 🛠 검증 도구 (재사용)

### PowerShell UTF-8 헬퍼 — 🔴 필수

> PowerShell 5.1은 `Invoke-RestMethod`가 JSON을 UTF-8로 디코딩하지 못해 **한글이 깨진다**(`ë°ëª¨...`). 한글 라벨 검증이 필요하므로 반드시 아래를 쓸 것.

```powershell
$base = "http://15.164.84.176:8080/api/v1"
function J($m,$u,$h,$b){
  $p=@{Method=$m;Uri=$u;Headers=$h;UseBasicParsing=$true}
  if($b){$p.ContentType="application/json";$p.Body=[Text.Encoding]::UTF8.GetBytes($b)}
  try{$r=Invoke-WebRequest @p}
  catch{ $resp=$_.Exception.Response
         if($resp){$sr=New-Object IO.StreamReader($resp.GetResponseStream()); return "HTTP $($resp.StatusCode.value__): $($sr.ReadToEnd())"}
         return "ERR: $($_.Exception.Message)" }
  return [Text.Encoding]::UTF8.GetString($r.RawContentStream.ToArray())
}
$t = (J "Post" "$base/auth/login" $null (@{email="songwonseok1234@g.eulji.ac.kr";password="<비번>"}|ConvertTo-Json -Compress) | ConvertFrom-Json).data.accessToken
$h = @{Authorization="Bearer $t"}
J "Get" "$base/profiles/1/dashboard" $h $null
```

### 도구 함정

| 함정 | 회피 |
|---|---|
| **`$pid`는 PowerShell 예약 변수** — 대입 실패해도 스크립트가 안 멈추고 프로세스ID로 요청이 나감 | `$myProfileId` 등 다른 이름 |
| `Get-Content`로 UTF-8 파일 읽기 | **`-Encoding UTF8`** 필수 |
| `icacls "$env:USERNAME:R"` → 매개변수 오류 | **`"${env:USERNAME}:R"`** (중괄호) |
| **Git Bash의 `ssh`/`scp`** → `Host key verification failed` | **PowerShell로 통일** (known_hosts가 다름) |
| Hibernate 로그가 `alter table if exists profiles`로 줄바꿈 | grep 패턴을 넓게 |
| `insert into courses`가 여러 줄로 쪼개짐(`format_sql: true`) | `grep -A3 -i 'insert' \| grep -ic 'courses'` |
