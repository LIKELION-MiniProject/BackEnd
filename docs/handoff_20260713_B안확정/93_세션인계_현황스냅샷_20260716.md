## 3. ✅ 오늘 완료된 작업 상세

### ① 0.5학점 입력 지원 (규칙4 "0.5=credit 0" 합의 해제 — 원석 지시)

`Course.credit` **int → double**. 14파일.

| 항목 | 내용 |
|---|---|
| 바뀐 것 | `Course` 엔티티 / `CourseCreate·Update·Response` DTO / `CreditProgress`·`CategoryProgress`(earned·shortfall) / `SemesterGpa.earnedCredit` / `CourseLine.credit` / `DashboardResponse.requested·earnedCredits` / `CategoryView.current`(Integer→**Double**) / `RecoItemDto.credit` / `GpaCalculator` / `DiagnosisService` / `DashboardService` / `GpaTrendService` / `RecommendationService` |
| **안 바꾼 것** | **`required`는 전부 `int` 유지** — 요건 기준값(130·21·39)은 정수라 소수가 필요 없다. 소수는 "이수 학점" 쪽에만 생긴다. |
| 🔴 **숨은 버그 수정** | `GpaCalculator`의 `int gpaCredit += course.getCredit()` — Java 복합대입의 **암묵적 축소 캐스팅**으로 0.5가 조용히 잘려 GPA만 틀리는 유형. **컴파일 에러 없이 통과했다.** `double`로 수정. |
| 가드 복원 | `int` 타입 자체가 검증이었으므로, `CourseService.validateCredit()`로 **0 이상 30 이하 0.5 단위**만 허용. 위반 시 `400 COMMON-001`. |
| **DB 마이그레이션** | Hibernate `ddl-auto: update`가 **`alter column credit set data type float(53)`** 실행. INT→FLOAT는 **확대 변환이라 무손실**. **로컬·EC2 양쪽에서 실증 완료.** |

**실증 결과(로컬)**: `POST credit=0.5` → 201 → **재기동 후 콜드 리드에서도 0.5 유지** → 진단 `21.0`→`21.5/130` → **GPA 불변(P학점이라 정상)** → `0.333` 전송 시 `400`.

### ④ 🔴 `build_data.py` 키 버그 수정 — 교과목코드 → **(교과목명, 교과목코드) 쌍**

## 9. 🛠 검증 도구

### PowerShell UTF-8 헬퍼 — 🔴 필수

> PS 5.1은 `Invoke-RestMethod`가 JSON을 UTF-8로 못 읽어 **한글이 깨진다**(`ë°ëª¨...`).

```powershell
$base = "http://15.164.84.176:8080/api/v1"
function J($m,$u,$h,$b){
  $p=@{Method=$m;Uri=$u;Headers=$h;UseBasicParsing=$true;TimeoutSec=120}
  if($b){$p.ContentType="application/json";$p.Body=[Text.Encoding]::UTF8.GetBytes($b)}
  try{$r=Invoke-WebRequest @p}
  catch{ $resp=$_.Exception.Response
         if($resp){$sr=New-Object IO.StreamReader($resp.GetResponseStream()); return "HTTP $($resp.StatusCode.value__): $($sr.ReadToEnd())"}
         return "ERR: $($_.Exception.Message)" }
  return [Text.Encoding]::UTF8.GetString($r.RawContentStream.ToArray())
}
# Claude가 직접 쓸 수 있는 계정 (레포 공개 시드)
$t = (J "Post" "$base/auth/login" $null (@{email="demo1@passport.ac.kr";password="Passport1!"}|ConvertTo-Json -Compress) | ConvertFrom-Json).data.accessToken
$h = @{Authorization="Bearer $t"}
J "Get" "$base/requirements/BIGDATA_AI" $h $null       # 요건 조회 (소유 무관)
J "Get" "$base/profiles/1/dashboard" $h $null          # → 403 PROFILE-003 이 정상(소유검증 동작)
```

### 도구 함정

| 함정 | 회피 |
|---|---|
| **`$pid`는 PowerShell 예약 변수** | `$myProfileId` 등 다른 이름 |
| `Get-Content`로 UTF-8 파일 | **`-Encoding UTF8`** 필수 |
| **Git Bash의 `ssh`/`scp`** → `Host key verification failed` | **PowerShell로 통일** |
| **중첩 heredoc**(`ssh "... <<'PY' ... PY"`)에서 파이썬 f-string 따옴표 깨짐 | **`.py` 파일로 scp 후 실행** |

| 캐시 JSON의 방향별 과목 필드는 **`recommendations`** | ~~`items`~~ 아님 (⚠️ Claude가 이전에 틀렸음) |
