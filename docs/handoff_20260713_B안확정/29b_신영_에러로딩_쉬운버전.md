# 신영님께 — 로딩 화면·에러 화면 배치 가이드

화면마다 **"불러오는 중" 표시**와 **"문제 발생" 표시**가 필요한데, 어디에 어떤 형태로 넣으면 되는지 정리했습니다. 어려운 용어 없이 필요한 것만 담았어요.

---

## 먼저, 상태는 크게 4가지입니다

화면은 늘 이 넷 중 하나예요.

1. **불러오는 중** — 정보를 가져오는 동안 잠깐 보이는 상태.
2. **정상** — 정보가 도착해 화면에 잘 표시됨.
3. **문제 발생** — 뭔가 실패했을 때. 이때는 항상 **[다시 시도] 버튼**을 함께 넣습니다.
4. **비어 있음** — 아직 보여줄 데이터가 없을 때. "아직 ○○이 없어요, 먼저 △△해 주세요" 안내.

> 핵심 원칙: **화면 전체를 덮지 않기.**
> 왼쪽 메뉴와 상단 제목은 그대로 두고, **정보가 들어올 그 영역만** 로딩·에러 표시로 바꿔주세요.

---

## 로딩 표시는 두 종류면 충분합니다

- **회색 자리표시(스켈레톤)** : 카드나 표가 뜰 자리에 내용 대신 **회색 박스**를 잠깐 보여줍니다. "곧 여기에 내용이 들어옵니다" 신호예요.
- **버튼 내부 스피너** : 버튼을 눌렀을 때 **버튼 안에서 작게 도는 표시**. (예: 로그인 버튼을 누르면 버튼 안에서 스피너)

여기에 **"문제 발생" 카드 1종**, **"비어 있음" 카드 1종**만 더하면 대부분 커버됩니다.

---

## 화면별 배치

### 로그인 · 회원가입
- **로딩**: 제출 버튼 **내부 스피너** (전체 화면 로딩 아님).
- **문제 발생**: 해당 입력칸 **바로 아래 빨간 안내 문구**. 예: "이미 가입된 이메일이에요", "비밀번호는 8자 이상이에요".

### 홈(대시보드)
- **로딩**: 요약 카드 자리에 **회색 자리표시 카드**.
- **문제 발생**: 그 영역에 "불러오지 못했어요 [다시 시도]".
- **비어 있음**: "먼저 수강 이력을 입력해 주세요" + 입력 이동 버튼.

### 프로필(내 정보)
- **로딩**: 조회 시 **회색 자리표시**, 저장 시 **저장 버튼 내부 스피너**.
- **문제 발생**: "저장하지 못했어요" 알림.

### 수강 이력(입력/목록)
- **로딩(목록)**: 표 자리에 **회색 줄 5개**.
- **로딩(복사·붙여넣기 입력)**: 이 과정은 **다소 시간이 걸립니다.** 그래서 "수강 이력을 분석하고 있어요…" 같은 **조금 더 눈에 띄는 진행 표시**가 별도로 필요해요.
- **문제 발생**: "입력을 인식하지 못했어요. 형식을 확인하거나 직접 입력해 주세요".
- **비어 있음**: "아직 입력한 수강 이력이 없어요" + 입력 버튼.

### 졸업 인증(어학·봉사·논문)
- **로딩**: 상태 표시 자리에 자리표시, 저장은 버튼 내부 스피너.
- **문제 발생**: "저장하지 못했어요" 알림.

### 졸업 진단
- **로딩**: 달성도·부족 학점 영역에 **회색 자리표시**.
- **문제 발생**: "불러오지 못했어요 [다시 시도]".

### 성적 그래프(GPA)
- **로딩**: 그래프 자리에 **그래프 형태의 회색 자리표시**.
- **문제 발생**: "불러오지 못했어요 [다시 시도]".
- **비어 있음**: "아직 성적 정보가 없어요".

### AI 분석(과목 추천) — 가장 중요합니다
상태가 여러 가지라 특히 신경 써야 하는 화면이에요.

- **로딩**: 방향 탭과 추천 카드 자리에 **회색 자리표시** (왼쪽 메뉴·상단 제목·상단 통계 카드는 유지).
- **정상**: 초록색 **"AI 분석 완료"** 배지 + 추천 카드.
- **기본 추천 상태**: AI가 일시적으로 응답하지 못할 땐 **노란색 "기본 추천" 배지** + "지금은 기본 추천을 보여드려요" 한 줄.
- **과목이 적은 방향**: 어떤 방향은 맞는 과목이 몇 개 안 돼요. 그럴 땐 카드가 적게 나오고 **"이 방향에 맞는 과목이 N개예요"** 안내 박스.
- **주의 문구(빨간 글씨)**: '시험 중심 방향', '팀플 중심 방향' 탭 아래에 **빨간 글씨로 짧은 주의 문구**. 예: "시험 비중이 높아 부담이 될 수 있어요". (문구는 서버에서 자동으로 내려줘요. 신영님은 **빨간 글씨가 들어갈 자리·스타일**만 잡아 주시면 됩니다.)
- **문제 발생**: "추천을 불러오지 못했어요 [다시 시도]".

---

## 신영님이 만들어 주시면 되는 것 (체크리스트)

- [ ] **회색 자리표시(스켈레톤)** — 카드용 / 표 줄용 / 그래프용 / (AI분석) 탭+카드용
- [ ] **버튼 내부 스피너** 1종
- [ ] **알림(토스트)** 1종 — 초록(성공)·빨강(실패)·노랑(주의)
- [ ] **"문제 발생" 카드** 1종 (일러스트 + 문구 + [다시 시도])
- [ ] **"비어 있음" 카드** 1종 (일러스트 + 문구 + 다음 행동 버튼)
- [ ] **AI 분석 전용**: 노란 "기본 추천" 배지 / "과목이 N개예요" 안내 박스 / **빨간 주의 문구** 스타일
- [ ] **수강 이력 붙여넣기용** "분석 중" 진행 표시 (다소 긴 로딩용)
- [ ] **로그인·회원가입** 입력칸 아래 **빨간 안내 문구** 스타일

---

## 문구 톤 예시 (부드럽고 다음 행동을 안내하는 느낌)

- 로딩: **"불러오는 중이에요…"**
- 비어 있음: **"아직 ○○이 없어요. 먼저 △△해 주세요."**
- 문제 발생: **"○○을 불러오지 못했어요. 잠시 후 다시 시도해 주세요."** + [다시 시도]
- 기본 추천: **"지금은 기본 추천을 보여드려요."**
- 과목 적은 방향: **"이 방향에 맞는 과목이 N개예요."**
- 주의 문구: **"시험 비중이 높아 부담이 될 수 있어요."** / **"팀플·발표가 많은 도전 방향이에요."**

궁금한 점 있으면 편하게 말씀해 주세요.
