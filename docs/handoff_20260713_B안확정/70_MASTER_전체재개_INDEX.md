## 1. 프로젝트 한 줄
**PassPort** — 을지대 빅데이터인공지능전공 학생이 성적·졸업요건을 입력하면 ① 졸업요건 달성도를 **규칙으로 진단**하고 ② 다음 학기 과목을 **AI가 방향별로 추천**하는 개인화 학사 대시보드. (멋사 미니프로젝트 3팀. 마감 7/17 22:00, 발표 7/20.)
- 팀: 송원석(PM·BE·AI) / 이은종(BE·데이터) / 황인서(FE) / 임신영(디자인).
- 대상 학과 1개 하드코딩(`deptCode="BIGDATA_AI"`), Web 전용.

## 2. 핵심 설계 (반드시 유지)
1. **사실 판정은 규칙, AI는 파싱·추천·설명만.** 졸업가능·학점·GPA·요건충족은 100% Java/Python 규칙. AI는 "규칙이 만든 후보에서 과목 선택 + 이유 2줄"만.
2. **AI 추천 = B안(방향성).** 5방향(규칙 분류) 각각에 AI가 과목 추천. 방향 탭/비교 전환은 프론트가 처리.
3. **라이브 브릿지(최신).** POST /recommendations는 유저 데이터(성적·요건·자격증)가 **바뀌었을 때만** 실시간 AI 재분석(5~6초), 안 바뀌면 캐시. GET은 캐시 조회. (지문=SHA-256)
4. **시크릿은 환경변수만.** `.env`(GEMINI_API_KEY·GEMINI_MODEL·JWT_SECRET 등) 커밋 금지.
