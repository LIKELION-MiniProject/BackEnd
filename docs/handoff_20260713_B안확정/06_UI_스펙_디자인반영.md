# 06. UI 스펙 — 디자인 시안(4종 목업) 반영

> 근거: 디자인팀(신영) AI 분석 페이지 시안 4종 스크린샷(2026-07-13). ⚠️ 최종 문구·색·간격은 신영 PNG를 SSOT로. 아래는 데이터 바인딩 관점 해설.

## 1) 화면 골격 (공통)

```
┌───────┬──────────────────────────────────────────────┐
│ 사이드바 │  헤더:  "AI 분석"            [초록 배지: AI 추천 완료] │
│ (고정)  │  ── (변형) 상단 통계 카드 4개 ──                  │
│  로고   │  [방향 탭: 졸업요건집중형 | 전공심화형 | 학점안정형 | ...] │
│  홈     │   ↳ caution 있으면 탭 아래 빨간 글씨               │
│  성적   │  ┌ 카드1 ┐┌ 카드2 ┐ ... (세로 5장)               │
│  AI분석 │  │번호·과목명·학점/구분 · 이유칩3 │                 │
│  마이   │  └───────┘└───────┘                          │
└───────┴──────────────────────────────────────────────┘
```

- **사이드바**: Pass Port 로고 + 네비(홈/성적/AI분석/마이). 활성 메뉴 강조. (시안엔 흰색·파란색 두 버전 — 디자인 확정 따름)
- **헤더**: 좌측 "AI 분석" 타이틀. 우상단 **초록 배지**("AI 추천 완료" + 생성 시각). → `source`가 `fallback`이면 이 자리 또는 별도로 **"기본 추천"** 배지.

## 2) 상단 통계 카드 (일부 변형에만 존재 — 선택)

시안 우측 2종에 4개 카드(예: `98%`, `74%`, `완료`, `5개`)가 있음. 바인딩 후보:
| 카드 | 값 예시 | 데이터 출처 |
|---|---|---|
| 졸업 달성률 | 98% | diagnosis / dashboard 집계 |
| 전공 이수율 | 74% | diagnosis (전공 이수/70) |
| 졸업 인증 | 완료/미완 | certification |
| 추천 과목 수 | 5개 | 현재 방향 recommendations 길이 |

> ⚠️ 통계 카드는 추천 API가 아니라 **대시보드/진단 API 값**. 추천 응답엔 없음. 넣을지 여부는 디자인·일정 따라 선택(MVP에선 생략 가능).

## 3) 방향 탭

- `directions[]` 순서·개수대로 렌더. 시안은 3탭 노출형이지만 **확정 방침은 5방향 노출**(가드로 얇은 방향은 카드 수 축소).
- 활성 탭 = `defaultDirectionId`(첫 진입). 탭 라벨 = 방향 `name`.
- **caution**: 활성(또는 각) 탭 아래에 `caution` 문자열을 **빨간 글씨**로. null이면 미표시. (편향 방향 ④시험형·⑤협업형에만 값 존재)
- (선택) 탭 아래 방향 `description` 한 줄 표기.

## 4) 과목 추천 카드 (핵심, 5장)

각 카드 구성(시안 기준):
- 좌측 **번호 배지**(1~5).
- **과목명**(굵게) + 하위에 **학점·이수구분**(예: "전공필수 · 3학점").
- 우측에 **이유 칩 3개**(가로 배열), 색상으로 관점 구분:

| 칩 | 내용 | reasons 인덱스 | 색(시안 추정) |
|---|---|---|---|
| 칩1 | 성향 맞춤 | `reasons[0]` (규칙) | 파랑/남색 |
| 칩2 | 과목 특성 | `reasons[1]` (AI) | 하늘/파랑 |
| 칩3 | 졸업 기여 | `reasons[2]` (AI) | 노랑 |

> 색 매핑은 시안에서 파랑 2 + 노랑 1로 보임. 정확한 색·라벨은 신영 PNG 확정 기준. 각 칩엔 짧은 라벨(성향/특성/졸업기여) + 본문 1문장.

## 5) 상태 4종

| 상태 | 트리거 | 표현 |
|---|---|---|
| 정상 | success && directions 있음 | 탭 + 카드 |
| 기본 추천 | `source == "fallback"` | 상단 "기본 추천" 배지(AI 실패→규칙 추천) |
| 로딩 | 요청 중 | 스켈레톤/스피너 |
| 빈·에러 | success==false or directions 빈 배열 | 안내 문구 + 재시도 버튼 |

## 6) 반응형·기타

- 데스크톱 우선(웹 전용 프로젝트). 카드 세로 스택, 좁아지면 이유 칩을 세로로.
- 스크롤: 카드가 뷰 넘어가면 자동 스크롤(회의록 확인 사항).
- 마이페이지 사진 깨짐 방지는 인서 처리(회의록).

## 7) 데이터 → 화면 요약

```
data.directions        → 방향 탭들
data.defaultDirectionId→ 첫 활성 탭
active.name/description → 탭 라벨/설명
active.caution         → 빨간 경고(있을 때만)
active.recommendations → 카드 5장
  .courseName/.credit  → 카드 제목/학점
  .reasons[0/1/2]      → 이유 칩 3개(파랑/파랑/노랑)
data.source=="fallback"→ "기본 추천" 배지
(통계 카드는 진단/대시보드 API에서 별도 바인딩)
```
