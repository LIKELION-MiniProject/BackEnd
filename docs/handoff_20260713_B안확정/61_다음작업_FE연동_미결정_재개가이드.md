## 2. FE 연동 — 무엇을·왜·어떻게 (요약, 상세는 54/55)
연동 = 화면(프론트)을 실제 백엔드에 연결해 진짜 데이터가 흐르게 하는 것. 인서가 코드 작성, 원석이 백엔드 보장.
순서: **① API 클라이언트(토큰 자동주입) → ② 로그인/온보딩 분기(me.profileId) → ③ 프로필 생성 화면 → ④ 성적·요건 입력 실 API → ⑤ 진단/대시보드(+semesterGpa) → ⑥ AI 분석(POST=실시간 6초·GET=캐시, 로딩 필수) → ⑦ 상태 4종 + E2E 관통.**

### AI 분석 연동 핵심(라이브 브릿지 반영)
- **"분석하기"(POST)** = 데이터 바뀌면 실시간 재분석(**5~6초, 로딩 UI 필수**), 안 바뀌면 즉시 캐시.
- **재방문(GET)** = 마지막 결과 조회(AI 미호출).
- **방향 탭/비교 전환** = 이미 받은 `directions[]`에서 프론트가 전환(서버 재호출 없음).
- 렌더: `directions[]`(탭)·`defaultDirectionId`(기본)·`caution`(빨간글씨,null이면 숨김)·`thin`(얇은 방향 안내)·`category`+`credit`·`reasons[0/1/2]`(성향/특성/졸업기여)·`source==fallback`→"기본 추천" 배지.
- ⚠️ **실데이터 라이브는 현재 방향 2개(FAST_GRAD·MAJOR_DEEP)만** — 핵심교양 과목↔영역 매핑 부재(BE 진단이 `lackingAreas`를 빈 배열로 넘김). 데모 캐시는 4방향. 화면은 `directions[]` 길이만큼 렌더하면 자동 대응.

## 4. 검증(재현) 방법 — 서버 켜고 curl (호스트, 검증됨)
```powershell
# 서버: .\gradlew bootRun  (환경변수 JWT_SECRET/JWT_EXPIRATION 필요)
$login = Invoke-RestMethod -Method Post -Uri "http://localhost:8080/api/v1/auth/login" -ContentType "application/json" -Body ([Text.Encoding]::UTF8.GetBytes((@{email="demo1@passport.ac.kr";password="Passport1!"}|ConvertTo-Json)))
$h = @{ Authorization = "Bearer $($login.data.accessToken)" }
$pf = (Invoke-RestMethod -Uri "http://localhost:8080/api/v1/auth/me" -Headers $h).data.profileId
# 라이브 브릿지: 성적 추가 → POST 재분석(generatedAt 바뀜), 무변경 → 캐시 유지
```
- 팁: 한글 바디 UTF-8 바이트, 예약변수 금지, 새 터미널은 로그인부터, `gradlew test` 대신 bootRun+curl. 잠금파일은 삭제.
