# 29. 디자인(신영) 요구서 — 에러 / 로딩 페이지 배치 가이드

> 목적: PassPort 각 화면에서 **로딩 중 상태**와 **에러 상태**를 "어디에 · 어떤 형태로" 넣어야 하는지 디자인 기준을 정리. FE(인서)가 이 기준으로 구현하고, 신영이 해당 요소(스피너·스켈레톤·에러 일러스트·문구 톤)를 디자인해 전달.
> 원칙: **전체 페이지를 덮지 말 것.** 데이터가 들어오는 영역만 로딩/에러로 바꾸고, 사이드바·헤더 등 정적 프레임은 유지. 에러는 항상 **재시도 수단**을 함께.

---

## 0) 공통 상태 4종 (모든 데이터 화면 공통)

| 상태 | 트리거 | 표현 |
|---|---|---|
| 로딩 | API 요청 중 | 해당 영역에 **스켈레톤**(카드/표 형태 회색 박스) 또는 중앙 스피너 |
| 정상 | 200 응답 | 데이터 렌더 |
| 빈 상태 | 200이지만 데이터 없음 | 일러스트 + 안내 문구 + 다음 행동 버튼(예: "수강 이력 입력하기") |
| 에러 | 4xx/5xx/네트워크 | 에러 일러스트 + 사유 문구 + **[다시 시도]** 버튼 |

전역 처리(디자인 필요):
- **토큰 만료(401)**: 토스트 "로그인이 만료됐어요" → 로그인으로 이동.
- **권한 없음(403, 타인 리소스)**: "접근 권한이 없어요" 안내 카드.
- **네트워크 끊김**: 상단 얇은 배너 "연결을 확인해주세요".
- **토스트/스낵바** 공통 컴포넌트 1종(성공/실패/경고).

## 1) 화면별 로딩·에러 위치 (전 페이지)

### 로그인 / 회원가입
- 로딩: **제출 버튼 내부 스피너**(버튼 비활성 + "처리 중"). 페이지 전체 로딩 아님.
- 에러: **입력 필드 하단 인라인 문구**(빨강). 예: 이메일 중복("이미 가입된 이메일이에요"), 비밀번호 8자 미만, 로그인 실패("이메일 또는 비밀번호를 확인해주세요").
- 필요 디자인: 인라인 에러 문구 스타일, 버튼 로딩 스피너.

### 홈 대시보드 (`GET /dashboard`)
- 로딩: 달성도 요약 카드·부족 항목 자리에 **스켈레톤 카드**.
- 에러: 대시보드 영역만 에러 카드 + [다시 시도]. 사이드바/헤더 유지.
- 빈 상태: 프로필/수강이력 없을 때 "먼저 수강 이력을 입력해 주세요" + 이동 버튼.
- 필요 디자인: 카드 스켈레톤, 요약 영역 에러/빈 카드.

### 프로필 등록/조회/수정
- 로딩: 조회 시 폼 자리에 스켈레톤. 저장 시 **저장 버튼 스피너**.
- 에러: 저장 실패 토스트 + 필드 인라인. 조회 실패 시 폼 영역 에러.
- 필요 디자인: 폼 스켈레톤, 저장 버튼 로딩.

### 수강 이력 입력/조회 (복붙 AI 파싱 포함)
- 로딩(조회): 목록 표 자리에 **행 스켈레톤 5줄**.
- 로딩(복붙 파싱): 파싱은 시간이 걸릴 수 있음 → **"수강 이력을 분석하고 있어요" 진행 표시**(모달 또는 인라인 프로그레스). ⚠️ 이 로딩은 조금 길 수 있으니 별도 디자인 필요.
- 에러(파싱 실패): "입력을 인식하지 못했어요. 형식을 확인하거나 직접 입력해 주세요" + 재시도/수동입력 전환.
- 빈 상태: "아직 입력한 수강 이력이 없어요" + 입력 버튼.
- 필요 디자인: 표 행 스켈레톤, 파싱 진행 인디케이터, 파싱 실패 안내.

### 졸업 인증 체크 (어학·봉사·논문)
- 로딩: 상태 뱃지 자리 스켈레톤. 저장 시 버튼 스피너.
- 에러: 저장 실패 토스트.

### 졸업 진단 (`GET /diagnosis`)
- 로딩: 달성도/부족학점 영역 스켈레톤.
- 에러: 진단 영역 에러 카드 + [다시 시도].
- 필요 디자인: 진단 결과 카드 스켈레톤.

### 성적 트렌드 / GPA (`GET /gpa-trend`)
- 로딩: **그래프 자리 스켈레톤**(차트 형태 회색).
- 에러: 그래프 영역 에러 + [다시 시도].
- 빈 상태: 성적 데이터 없을 때 "성적 데이터가 아직 없어요".
- 필요 디자인: 차트 스켈레톤.

### ⭐ AI 분석 (추천) — `GET/POST /recommendations` (가장 중요)
가장 신경 써야 할 화면. 상태가 많음:
1. **로딩**: 추천 생성/조회 중 → **방향 탭 + 카드 영역만 스켈레톤**(탭 자리 회색 pill 5개 + 카드 5장 스켈레톤). 사이드바·헤더·상단 통계 카드는 유지.
2. **정상(source=live/cache)**: 초록 "AI 분석 완료" 배지 + 방향 탭 + 카드. (cache도 정상 취급)
3. **기본 추천(source=fallback)**: **앰버 "기본 추천" 배지** + 규칙 추천. AI 실패 시. 디자인: 앰버 배지 + "지금은 기본 추천을 보여드려요" 한 줄.
4. **thin 방향**: 매칭 과목이 5개 미만인 방향 → 탭은 보이되 카드가 적고, **"이 방향에 맞는 과목이 N개예요" thin 안내 박스**. (caution과 겹치지 않음 — thin이면 caution 없음)
5. **caution(편향 경고)**: 시험·개별평가형/협업·활동형 탭 아래 **빨간 글씨** 경고. (서버 caution 필드가 있을 때만)
6. **빈·에러**: 추천 실패 시 "추천을 불러오지 못했어요" + [다시 시도].
- 필요 디자인: 탭+카드 스켈레톤, 앰버 "기본 추천" 배지, **thin 안내 박스**, **caution 빨간 경고 스타일**, 에러/재시도 카드.

## 2) 신영에게 요청하는 산출물 (체크리스트)

- [ ] 스켈레톤 컴포넌트 세트: 카드형 / 표 행형 / 차트형 / 방향탭+카드형.
- [ ] 스피너(버튼 내부용 소형 1종).
- [ ] 토스트/스낵바 1종(성공·실패·경고 3색).
- [ ] 에러 상태 카드(일러스트 + 문구 + [다시 시도] 버튼) 1종.
- [ ] 빈 상태 카드(일러스트 + 안내 + 액션 버튼) 1종.
- [ ] AI 분석 전용: 앰버 "기본 추천" 배지 · **thin 안내 박스** · **caution 빨간 경고** 스타일.
- [ ] 수강이력 **복붙 파싱 진행 인디케이터**(다소 긴 로딩용).
- [ ] 인라인 폼 에러 문구 스타일(로그인/회원가입/프로필).
- [ ] 문구 톤 가이드(에러/빈 상태 문장은 부드럽고 다음 행동 유도).

## 3) 문구 톤 예시 (공통)
- 로딩: "불러오는 중이에요…"
- 빈: "아직 ○○이 없어요. 먼저 △△해 주세요."
- 에러: "○○을 불러오지 못했어요. 잠시 후 다시 시도해 주세요." + [다시 시도]
- 기본추천: "지금은 기본 추천을 보여드려요."
- thin: "이 방향에 맞는 과목이 N개예요."
- caution: (시험형) "시험 비중이 높아 시험 부담이 클 수 있어요." / (협업형) "팀플·발표 비중이 높은 선택적 도전이에요."
