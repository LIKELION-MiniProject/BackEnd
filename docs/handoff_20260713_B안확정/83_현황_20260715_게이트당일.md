## 4. ⚠️ 중요 발견 — persona 패턴 산출 조건 (게이트 데모 리스크)

persona 로직은 **정상 동작**하나, 조건이 있다:

```
persona 브릿지 성공: studentKey=202312345 pattern=none     코드매핑=0과목 미매칭=1과목
persona 브릿지 성공: studentKey=202312345 pattern=none     코드매핑=1과목 미매칭=1과목
persona 브릿지 성공: studentKey=202312345 pattern=none     코드매핑=2과목 미매칭=1과목
persona 브릿지 성공: studentKey=202312345 pattern=balanced 코드매핑=3과목 미매칭=1과목  ← 전환
persona 브릿지 성공: studentKey=202312345 pattern=balanced 코드매핑=6과목 미매칭=1과목
```

**조건 2가지 — 둘 다 충족해야 패턴이 나온다:**

1. **과목명이 `passport-ai/data/raw/courses_eval.csv` 카탈로그와 정확히 일치**해야 매핑됨
   - 82 문서 예시의 `"데이터베이스"`는 **카탈로그에 없음** → 미매칭
2. **매핑돼도 평가특성(①시험/②과제/③팀플/④발표) 데이터가 있어야** 패턴 산출
   - `데이터분석기초`·`인공지능개론`은 매핑은 되나 **특성이 비어 있어** `pattern=none`
   - 전체 182행 중 **140행만** 특성 보유 (주로 교양 과목)
   - 특성 보유 과목(`생명윤리`·`언어의이해`·`신화의이해`·`동서고전문학`) 추가 후 **`balanced`(균형 성장형) 산출 확인** ✅

> ### ✅ 리스크 해소됨 (2026-07-15 저녁)
> 원석 실데이터에 **특성 보유 교양이 7과목** 포함되어 있어 임계값(3과목)을 넘겼다 → **persona = `균형 성장형(BALANCED)` 산출 확인.** 시연용 과목을 억지로 넣을 필요가 없었다.
> 단, **과목명을 카탈로그 정확명으로 입력해야** 매핑된다(예: `데이터분석의기초` → **`데이터분석의기초(MD)`**). 상세는 [86 §6](86_캐시_persona_메커니즘_실측기록.md).
