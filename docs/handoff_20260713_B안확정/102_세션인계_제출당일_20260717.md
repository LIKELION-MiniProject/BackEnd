## 4. 🔴 `VITE_API_BASE_URL` — 우리 문서가 틀렸다 (인서님 세션이 맞음)

### 무슨 일

우리 문서(92·97·98·**100**)가 `.env.production`에 **`VITE_API_BASE_URL=/api/v1`**로 넣으라고 지시했다. 인서님 세션이 **"FE 코드에 이미 `/api/v1`이 포함돼 있어 그대로 하면 `/api/v1/api/v1/auth/login` → 전부 404"**라고 반박하고, **빈 값으로 빌드**한 뒤 산출물에서 이중경로 0건을 확인했다.

**인서님 세션이 맞다.** 우리 문서는 **FE 코드를 보지 않고 구조를 가정**하고 쓴 것이다.

```js
// 100 문서의 코드 예시 — 이건 "가정"이었다
const API = import.meta.env.VITE_API_BASE_URL;   // "/api/v1"
fetch(`${API}/profiles/${id}/courses`)
```

### 핵심 — 최종 URL만 맞으면 방식은 무관

| 방식 | base | 코드 | 최종 URL |
|---|---|---|---|
| 우리 가정 | `/api/v1` | `${API}/auth/login` | `/api/v1/auth/login` ✅ |
| **실제** | `` (빈 값) | `/api/v1/auth/login` | `/api/v1/auth/login` ✅ |

둘 다 nginx `location /api/`에 매칭 → Spring 도달. **빈 값 빌드가 맞다.**

### ⚠️ 단 하나의 함정

`.env.production`에 **`VITE_API_BASE_URL=` (등호까지) 키가 존재**해야 `""`가 된다. **키를 통째로 지우면 `undefined`** → `undefined/api/v1/...` 로 깨진다.

### 🔴 남은 일 — 문서 정정

**92 · 97 · 98 · 100 문서의 `VITE_API_BASE_URL=/api/v1` 지시를 정정해야 한다.** 단, **dist를 받아 실제 구조를 확인한 뒤** 고칠 것 — 지금 고치면 또 추측이 된다.

## 5. 🔴 SSH(22) 막힘 — 핫스팟 CGNAT

### 상태 (실측)

```
포트 22   🔴 timeout      ← dist 배포 불가
포트 80   ✅ 열림 (200)
포트 8080 ✅ 열림 (200)
내 공인 IP: 211.234.207.177
github.com:22, gitlab.com:22 → ✅ 통함   (= 통신사 22번 차단 아님)
보안그룹: launch-wizard-3 = PassPort-Server의 것 맞음 (확인 완료)
```

### 원인

**모바일 핫스팟의 CGNAT.** 여러 사용자가 IP 풀을 공유해 **목적지·세션마다 다른 공인 IP로 나갈 수 있다.** `api.ipify.org`가 본 IP와 EC2로 나갈 때의 IP가 다르다. 그래서 "내 IP"로 고정하면 안 통한다. 웹(80·443)은 프록시를 타서 티가 안 나지만 SSH는 직결이라 드러난다.

### 🔴 탄력적 IP를 소스에 넣으면 안 된다

원석이 물어본 것 — **불가.** 보안그룹 인바운드 **소스**는 "**누가 접속해 오는가**"(= 원석 PC IP)다. EIP(`15.164.84.176`)는 **서버 자신의 주소**라 넣으면 "서버가 자기 자신에게 SSH할 때만 허용"이 된다.

### 선택지

| 방법 | 소스 | 평가 |
|---|---|---|
| **A. 위치 무관** | `0.0.0.0/0` | **가장 빠름.** SSH가 **키 인증**이라 `.pem` 없이 못 들어옴. 발표 후 인스턴스 종료 예정이라 노출 짧음 |
| **B. 통신사 대역** | `211.234.0.0/16` | ❌ **비권장.** CGNAT라 다른 대역으로 나가면 또 막힘 — 반복됨 |
| **C. 고정 회선** | 집/사무실에서 `내 IP` | **가장 안전.** 핫스팟 끄고 설정 |

> **급하지 않다.** SSH는 dist 배포 시에만 필요하고 **서비스는 정상**이다. dist 오는 시점에 맞춰 열면 된다.

### PowerShell UTF-8 헬퍼 (한글 깨짐 방지)

```powershell
$base = "http://15.164.84.176/api/v1"
function J($m,$u,$h,$b){
  $p=@{Method=$m;Uri=$u;Headers=$h;UseBasicParsing=$true;TimeoutSec=120}
  if($b){$p.ContentType="application/json";$p.Body=[Text.Encoding]::UTF8.GetBytes($b)}
  try{$r=Invoke-WebRequest @p}
  catch{ $resp=$_.Exception.Response
         if($resp){$sr=New-Object IO.StreamReader($resp.GetResponseStream()); return "HTTP $($resp.StatusCode.value__): $($sr.ReadToEnd())"}
         return "ERR: $($_.Exception.Message)" }
  return [Text.Encoding]::UTF8.GetString($r.RawContentStream.ToArray())
}
$t = (J "Post" "$base/auth/login" $null (@{email="demo1@passport.ac.kr";password="Passport1!"}|ConvertTo-Json -Compress) | ConvertFrom-Json).data.accessToken
$h = @{Authorization="Bearer $t"}
J "Get" "$base/requirements/BIGDATA_AI" $h $null      # 요건 (소유 무관)
J "Get" "$base/profiles/1/dashboard" $h $null          # → 403 PROFILE-003 이 정상
```
