### 멘트 (정직성 유지)

### ⚠️ 폴백 배지 시연 조건 (86 §3)

`source=fallback`은 **AI 실패 + 캐시 없음**일 때만 나온다. 정상 상태에서 신규 계정으로 POST하면 `live`가 떠서 **배지가 안 보인다**. 시연하려면 `.env` 임시 리네임으로 AI를 실패시켜야 한다.

```bash
# EC2 — 폴백 유도
mv ~/app/passport-ai/.env ~/app/passport-ai/.env.bak
# → 신규 계정으로 POST /recommendations → source=fallback, "기본 추천" 배지
# 시연 후 반드시 복구
mv ~/app/passport-ai/.env.bak ~/app/passport-ai/.env
```
> 🔴 **복구를 잊으면 이후 모든 AI 호출이 폴백된다.** 리허설에서 복구까지 1회 연습할 것.
